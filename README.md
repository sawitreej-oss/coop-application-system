# ระบบบันทึกใบสมัครเข้าสหกิจศึกษา (Ms-Coop 01-01)
### สำนักสหกิจศึกษา คณะวิทยาการจัดการ มหาวิทยาลัยราชภัฏเทพสตรี
**Cooperative Education Faculty of Management Science Thepsatri Rajabhat University**

ระบบเว็บแอพพลิเคชันสำหรับนักศึกษาและเจ้าหน้าที่ ในการบันทึกข้อมูลใบสมัครเข้าสหกิจศึกษา จัดเก็บข้อมูลอย่างเป็นระบบ ค้นหา ดูย้อนหลัง แก้ไขข้อมูล และสามารถสั่งพิมพ์เอกสารออกมาเป็นแบบฟอร์ม **Ms-Coop 01-01** ขนาด A4 พอดี 2 หน้า ตามรูปแบบต้นฉบับของคณะวิทยาการจัดการ 100%

## ✨ คุณสมบัติเด่นของระบบ

1. **บันทึกข้อมูลใบสมัครครบถ้วนตามแบบฟอร์ม Ms-Coop 01-01**:
   - **ส่วนที่ 1 ข้อมูลนักศึกษา**: ภาคการศึกษา, คำนำหน้า, ชื่อ-นามสกุล, เพศ, วัน/เดือน/ปีเกิด (คำนวณอายุอัตโนมัติ), รหัสประจำตัว, ชั้นปี, สาขาวิชา, ที่อยู่ครบถ้วน, โทรศัพท์, อีเมล, Line ID
   - **อัปโหลดรูปถ่ายหน้าตรงขนาด 1 นิ้ว**: รองรับไฟล์ JPG/PNG แสดงตัวอย่างรูปถ่าย และแสดงในกรอบรูปบนเอกสารพิมพ์
   - **ส่วนที่ 2 ข้อมูลสถานที่ปฏิบัติงาน**: ชื่อหน่วยงาน, ผู้ประสานงาน, แผนกที่ปฏิบัติงาน, ที่อยู่หน่วยงาน, เบอร์ติดต่อ, วันที่ลงนาม
   - **ส่วนที่ 3 ผลการพิจารณา (สำหรับอาจารย์/คณะ)**: การตรวจสอบหน่วยกิต, GPA, รายวิชาที่ติด E/I/W, ความเห็นอาจารย์ที่ปรึกษา, ผลการพิจารณาของหัวหน้าสาขาวิชา และประธานหลักสูตร พร้อมผลสรุปของกรรมการสหกิจศึกษา

2. **ระบบจัดเก็บและจัดการข้อมูล (Database & Management)**:
   - บันทึกข้อมูลลงฐานข้อมูล JSON ของระบบในเครื่องอย่างถาวร
   - มีระบบ LocalStorage ในตัว ทำให้เปิดใช้งานได้แม้ไม่มีอินเทอร์เน็ตหรือไม่ได้เปิดเซิร์ฟเวอร์ (Offline Standalone)
   - หน้าค้นหาและกรองข้อมูลใบสมัครตามชื่อ, รหัสนักศึกษา หรือสาขาวิชา
   - ปุ่มลัด "พิมพ์", "แก้ไขข้อมูล", "ลบข้อมูล"
   - ส่งออกข้อมูลเป็น **Excel (CSV)** รองรับภาษาไทยสมบูรณ์แบบ
   - ส่งออกและนำเข้าไฟล์สำรองข้อมูล **JSON**

3. **การพิมพ์เอกสารราชการที่แม่นยำ (Pixel-Perfect A4 Print)**:
   - ออกแบบ CSS `@media print` สำหรับกระดาษ A4 สองหน้าพอดีเป๊ะ (หน้า 1: ข้อมูลนักศึกษาและสถานที่ฝึกงาน, หน้า 2: ผลการพิจารณาของคณะ)
   - มีตราสัญลักษณ์คณะ MS-TRU คมชัด
   - รองรับการพิมพ์เอกสารพร้อมข้อมูลนักศึกษา หรือสั่งพิมพ์ **"แบบฟอร์มเปล่า"** เพื่อนำไปแจกให้นักศึกษาเขียนด้วยลายมือ
   - สามารถเลือกรวมหรือแยกหน้า 2 ได้ตามความเหมาะสม

4. **ปุ่มทดสอบรวดเร็ว (Sample Data)**:
   - มีปุ่มคลิกเดียวใส่ข้อมูลตัวอย่างจริงของนักศึกษา เพื่อทดสอบระบบและดูตัวอย่างการพิมพ์ได้ทันที

## 🚀 วิธีเปิดใช้งานระบบ

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์ `start.bat` (แนะนำ)
1. ดับเบิ้ลคลิกไฟล์ `start.bat`
2. ระบบจะเริ่มทำงานและเปิดเว็บบราวเซอร์อัตโนมัติที่ `http://localhost:3000`

### วิธีที่ 2: เปิดโหมด Standalone / Offline
- ดับเบิ้ลคลิกไฟล์ `open_offline.bat` หรือดับเบิ้ลคลิกไฟล์ `public\index.html` เพื่อเปิดใช้งานในเบราว์เซอร์ได้ทันทีโดยไม่ต้องรันเซิร์ฟเวอร์

### วิธีที่ 3: รันผ่าน Terminal / Command Line
```powershell
cd C:\Users\Dell1\.gemini\antigravity\scratch\coop-application-system
agy-node server.js
```
จากนั้นเปิดบราวเซอร์ไปที่: `http://localhost:3000`

## 🖨️ คำแนะนำสำหรับการสั่งพิมพ์เอกสาร (Print to PDF / Paper)
เมื่อกดปุ่ม **"สั่งพิมพ์เอกสาร / บันทึกเป็น PDF"** ในหน้าต่างการพิมพ์ของเว็บบราวเซอร์ (Chrome / Edge):
1. **ปลายทาง (Destination)**: เลือกเครื่องพิมพ์ที่ต้องการ หรือเลือก `Save as PDF` (บันทึกเป็น PDF)
2. **ขนาดกระดาษ (Paper size)**: เลือก `A4`
3. **ระยะขอบ (Margins)**: แนะนำให้เลือก `Minimum` หรือ `None` (ค่าเริ่มต้นก็สามารถพิมพ์ได้พอดี)
4. **ตัวเลือก (Options)**: ติ๊กถูกที่ช่อง **"Background graphics" (กราฟิกพื้นหลัง)** เพื่อให้รูปถ่ายและเส้นกรอบแสดงผลคมชัด 100%
